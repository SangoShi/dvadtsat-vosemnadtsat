Каждый файл char-001.js, char-002.js и т.д. — это данные одного персонажа.

═══ Как добавить картинки персонажа ═══════════════════════════════════

У каждого персонажа три вида картинок:

1. ФОТО (поляроид) — квадратное фото для карточки и модалки
2. БАННЕР — длинный баннер в шапке модального окна
3. ГАЛЕРЕЯ — 6 квадратных картинок в сетке 3×2

▸ Добавить фото на карточке:

1. Положи картинку в папку img/characters/ (например person2.png)
2. Открой нужный файл char-ХХХ.js
3. Найди строку:
   photo: null,
4. Замени null на имя файла в кавычках:
   photo: "person2.png",
5. Сохрани файл

▸ Добавить баннер:

1. Положи широкую картинку в img/characters/ (например banner-002.jpg)
2. В файле char-ХХХ.js найди:
   banner: null,
3. Замени на:
   banner: "banner-002.jpg",
4. Сохрани файл

▸ Добавить галерею (до 6 картинок):

1. Положи картинки в img/characters/ (например gal-2-1.jpg, gal-2-2.jpg…)
2. В файле char-ХХХ.js найди:
   gallery: [null, null, null, null, null, null],
3. Замени null на имена файлов по порядку:
   gallery: ["gal-2-1.jpg", "gal-2-2.jpg", "gal-2-3.jpg", null, null, null],
4. Сохрани файл

Готово! Обнови сайт (Ctrl+Shift+R), и картинки появятся.

═══ Как добавить нового персонажа ═══════════════════════════════════

1. Скопируй любой файл char-ХХХ.js и переименуй (например char-007.js)

2. Поменяй поле id на новое:
   id: "char-007",

3. Заполни остальные поля (имя, nickname, role, группу…)

4. Добавь строку в index.html перед </body>, после других char-ХХХ.js:
   <script src="js/characters/char-007.js"></script>

5. Сохрани оба файла

Готово! Персонаж появится на сайте.

═══ Как добавить файл карточки для SillyTavern ══════════════════════

1. Положи карточку (PNG или JSON) в папку files/characters/
   (например anya.png или ivan_card.json)

2. В файле персонажа (char-ХХХ.js) найди строку:
   file: null,

3. Замени null на имя файла:
   file: "anya.png",

4. Сохрани файл

Готово! Кнопка «Скачать» в модальном окне будет работать.
