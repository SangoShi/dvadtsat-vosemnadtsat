# Двадцать-Восемнадцать

Статический сайт для ролевой истории "Двадцать-Восемнадцать" (Россия, 2018).

## Запуск

Открой `index.html` в браузере или запусти локальный сервер:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000` в браузере.

## Структура

- `index.html` — главная страница
- `css/style.css` — стили
- `js/data.js` — весь контент сайта (редактируй здесь)
- `js/app.js` — логика навигации и рендеринга
- `js/music.js` — фоновая музыка с эффектами
- `js/smooth-scroll.js` — плавный скролл
- `music/` — фоновая музыка
- `img/` — изображения

## Редактирование контента

Весь текст сайта находится в `js/data.js`. Меняй значения в кавычках, названия полей (слева от двоеточия) не трогай.
