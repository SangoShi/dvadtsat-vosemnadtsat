Все пути к картинкам прописываются в файле img/paths.js.

═══ Картинка персонажа ═══════════════════════════════════════════════

1. Положи картинку в папку img/characters/ (например, person7.png)

2. Открой файл персонажа js/characters/char-ХХХ.js
   (например char-001.js, char-002.js и т.д.)

3. Найди строку:
   photo: null,

4. Замени null на имя файла в кавычках:
   photo: "person7.png",

5. Сохрани файл

Готово! Обнови сайт (Ctrl+Shift+R), и картинка персонажа появится.

═══ Баннер для раздела «Персонажи» ═══════════════════════════════════

1. Положи картинку в папку img/ (например, characters-banner.jpg)

2. Открой файл img/paths.js

3. Найди строку:
   charactersBanner: "placeholder.jpg",

4. Замени на имя нового файла:
   charactersBanner: "characters-banner.jpg",

5. Сохрани файл

Так же для:
  • Раздел «Мир»:  knowledgeBanner
  • Раздел «Рекомендации»:  recommendationsBanner
  • Главная страница:  hero

═══ Файл карточки для SillyTavern ════════════════════════════════════

1. Положи карточку (PNG или JSON) в папку files/characters/
   (например, anya_card.png или ivan.json)

2. Открой файл персонажа js/characters/char-ХХХ.js

3. Найди строку:
   file: null,

4. Замени null на имя файла:
   file: "anya_card.png",

5. Сохрани файл

Готово! Кнопка «Скачать» в карточке персонажаbud работает.

═══════════════════════════════════════════════════════════════════════

Если что-то не работает:
- Обнови страницу с очисткой кэша (Ctrl+Shift+R)
- Проверь, что имя файла в коде точно совпадает с именем файла в папке
- Убедись, что файл действительно лежит в нужной папке
