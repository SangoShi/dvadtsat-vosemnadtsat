КАК ДОБАВИТЬ КАРТИНКИ — короткая инструкция
════════════════════════════════════════════════════════════════════════

Теперь все картинки меняются в ОДНОМ файле: img/paths.js
Он простой и понятный, открывай его в блокноте и вписывай имена файлов.

────────────────────────────────────────────────────────────────────────
1. ФОТО ПЕРСОНАЖЕЙ
────────────────────────────────────────────────────────────────────────
   а) Положи файл в папку img/characters/ (например, anya.jpg)
   б) Открой img/paths.js
   в) Найди раздел "characters: {" 
   г) Впиши:
      "char-001": "anya.jpg",
      
      где char-001 — это id персонажа из js/data.js
      
   д) Сохрани, залей на GitHub

────────────────────────────────────────────────────────────────────────
2. БАННЕР РАЗДЕЛА «ПЕРСОНАЖИ»
────────────────────────────────────────────────────────────────────────
   а) Положи файл banner.jpg в папку img/characters/
   б) Открой img/paths.js
   в) Найди строку charactersBanner:
      charactersBanner: "banner.jpg",
   г) Если файл называется по-другому, впиши его имя
   д) Сохрани, залей на GitHub

────────────────────────────────────────────────────────────────────────
3. ПЕРСОНАЖИ ПО БОКАМ НА ГЛАВНОЙ
────────────────────────────────────────────────────────────────────────
   а) Положи файлы в папку img/hero/ (лучше PNG без фона)
   б) Открой img/paths.js
   в) Найди раздел hero: { ... }
   г) Впиши:
      left: "left.png",
      right: "right.png"
   д) Сохрани, залей на GitHub

────────────────────────────────────────────────────────────────────────
4. МУЗЫКА
────────────────────────────────────────────────────────────────────────
   а) Положи файл в папку music/ (track.mp3)
   б) Открой js/data.js
   в) Найди раздел music: { src: ... }
   г) Если заменяешь файл, поменяй ?v=2 на ?v=3 чтобы браузер обновил:
      src: "music/track.mp3?v=3",
   д) Сохрани, залей на GitHub

════════════════════════════════════════════════════════════════════════

Всё! После изменений:
1. Сохрани файл
2. Залей на GitHub (git add, commit, push)
3. Подожди 1–2 минуты
4. Обнови сайт (Ctrl+Shift+R)
