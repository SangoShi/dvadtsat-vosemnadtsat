  КАК ДОБАВИТЬ КАРТИНКИ НА САЙТ — простая инструкция
═══════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────────┐
│ 1. ФОТО ПЕРСОНАЖА (карточка на странице Персонажи)                  │
└─────────────────────────────────────────────────────────────────────┘

  ШАГ 1: Положи файл в папку
    D:\dvadtsat-vosemnadtsat\img\characters\
    Например: anya.jpg или petya.png

  ШАГ 2: Открой js/data.js в блокноте или редакторе

  ШАГ 3: Найди своего персонажа в списке characters

  ШАГ 4: В строке image: напиши путь к файлу:
    
    ДО:
      image: null,
    
    ПОСЛЕ:
      image: "img/characters/anya.jpg",

  ШАГ 5: Сохрани data.js, залей на GitHub, через 2 минуты обнови сайт


┌─────────────────────────────────────────────────────────────────────┐
│ 2. ПОРТРЕТЫ ПО БОКАМ ЗАГОЛОВКА (главная страница)                   │
└─────────────────────────────────────────────────────────────────────┘

  ШАГ 1: Положи два файла в папку
    D:\dvadtsat-vosemnadtsat\img\hero\
    С именами: left.png и right.png
    (лучше PNG без фона, прозрачный)

  ШАГ 2: Всё! Сайт сам подхватит их

  Если хочешь другие имена файлов:
    - Открой js/data.js
    - Найди строки portraits (примерно строка 30)
    - Впиши свои пути:
        left: "img/hero/левый_персонаж.png",
        right: "img/hero/правый_персонаж.png"


┌─────────────────────────────────────────────────────────────────────┐
│ 3. БАННЕР ВВЕРХУ СТРАНИЦЫ «ПЕРСОНАЖИ»                               │
└─────────────────────────────────────────────────────────────────────┘

  ШАГ 1: Положи файл banner.jpg в
    D:\dvadtsat-vosemnadtsat\img\characters\

  ШАГ 2: Открой index.html в блокноте

  ШАГ 3: Нажми Ctrl+F, найди: characters-hero

  ШАГ 4: Увидишь строку вроде:
    <div class="characters-hero" style="background-image: url('https://images...

  ШАГ 5: Замени адрес между url(' и ') на:
    img/characters/banner.jpg

    СТАНЕТ:
    <div class="characters-hero" style="background-image: url('img/characters/banner.jpg');">

  ШАГ 6: Сохрани, залей на GitHub


┌─────────────────────────────────────────────────────────────────────┐
│ 4. МУЗЫКА (фоновая песня)                                           │
└─────────────────────────────────────────────────────────────────────┘

  ШАГ 1: Положи файл track.mp3 в папку
    D:\dvadtsat-vosemnadtsat\music\

  ШАГ 2: Открой js/data.js, найди блок music (строка ~44)

  ШАГ 3: Впиши путь:
    src: "music/track.mp3?v=2",

  ⚠ ВАЖНО: Если ЗАМЕНЯЕШЬ старый файл на новый, поменяй цифру:
    ?v=2 → ?v=3
    Иначе браузер будет играть старую песню из памяти


┌─────────────────────────────────────────────────────────────────────┐
│ 5. ЗНАЧОК НА ВКЛАДКЕ БРАУЗЕРА (favicon)                             │
└─────────────────────────────────────────────────────────────────────┘

  ШАГ 1: Замени файл
    D:\dvadtsat-vosemnadtsat\img\favicon.svg
    на свой (с тем же именем)

  ШАГ 2: Всё! Залей на GitHub


┌─────────────────────────────────────────────────────────────────────┐
│ 6. ЛОГОТИП 20/18 (слева в шапке)                                    │
└─────────────────────────────────────────────────────────────────────┘

  ШАГ 1: Замени файл
    D:\dvadtsat-vosemnadtsat\img\logo.svg
    на свой (с тем же именем)

  ШАГ 2: Всё! Залей на GitHub


═══════════════════════════════════════════════════════════════════════
  ПОСЛЕ ЛЮБЫХ ИЗМЕНЕНИЙ:
═══════════════════════════════════════════════════════════════════════

  1. Открой PowerShell в папке D:\dvadtsat-vosemnadtsat
  2. Выполни команды (по одной):
       git add -A
       git commit -m "Добавлены фото персонажей"
       git push
  3. Подожди 1-2 минуты
  4. Открой сайт и нажми Ctrl+Shift+R (жёсткое обновление)

═══════════════════════════════════════════════════════════════════════
  ГДЕ ЧТО ЛЕЖИТ:
═══════════════════════════════════════════════════════════════════════

  js/data.js        — весь текст сайта и пути к картинкам
  index.html        — каркас сайта (редко трогаем)
  css/style.css     — цвета и стили (редко трогаем)
  img/characters/   — фото персонажей
  img/hero/         — портреты по бокам заголовка
  img/              — логотип и значок
  music/            — музыка
